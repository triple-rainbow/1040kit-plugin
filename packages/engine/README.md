# @1040kit/engine

Deterministic federal tax engine for 1040kit. Pure TypeScript, no runtime
dependencies. Tax facts in (integer cents), a computation graph of semantic
nodes out (integer dollars), each node with a trace of the facts, nodes and
parameters it read, and IRS citations.

The contract is `src/types.ts` (`EngineApi`); `src/index.ts` exports `engine`.

```sh
pnpm --filter @1040kit/engine test       # unit + golden tests
pnpm --filter @1040kit/engine typecheck
```

## Layout

| Path                                    | What                                                                                          |
| --------------------------------------- | --------------------------------------------------------------------------------------------- |
| `src/graph.ts`                          | `defineNode`, `evaluate` (topological, cycle check, trace capture), `resolveFactPath`         |
| `src/money.ts`                          | cents/dollars, half-up rounding, exact rate math (ppm)                                        |
| `src/params/ty2025.ts`, `ty2026.ts`     | per-year parameters, each with its source                                                     |
| `src/params/lines.ts`                   | node id -> form/line per year (`formLines`, `lineAliases`)                                    |
| `src/tax/table.ts`, `qdcg.ts`, `eic.ts` | Tax Table / Tax Computation Worksheet; QDCG worksheet; EIC Table                              |
| `src/forms/*.ts`                        | Form 1040, Schedules 1, 1-A, 2, B, C, E (Part I), EIC, SE, 8812; Forms 8829, 8959, 8960, 8995 |
| `src/scope.ts`, `src/required.ts`       | `checkScope`, `requiredFacts`                                                                 |
| `src/rules/*.ts`                        | `findDeductions`, `reviewChecks`, `compareScenarios`                                          |
| `src/explain.ts`                        | `explainLine`                                                                                 |
| `test/golden/*.json`                    | hand-worked golden returns (synthetic people)                                                 |
| `test/private/*.json`                   | owner's real returns; gitignored, loaded by the golden runner when present                    |

## Rounding

Facts are cents. A line that adds amounts adds cents first and rounds the
total half up (i1040gi, "Rounding Off to Whole Dollars"). Lines computed from
other lines use those lines' whole-dollar values, as on the paper form (so
Schedule SE line 13 is 50% of the rounded line 12).

## Known limits (flagged, not computed)

Everything outside spec §5 returns an `UnsupportedItem` from `checkScope`
(retirement distributions, Social Security, sales of stock/crypto, K-1,
foreign income, 1099-G, HSA, education credits, itemizing, MFS, digital
assets, Form 8995-A, a second Schedule C per person, W-2 box 12 codes needing
other forms, statutory employees, allocated tips, excess social security
withholding, kiddie tax, negative AGI). Schedule E: rental depreciation
(`rental_depreciation`), Form 8582 passive loss limits (`passive_loss_8582`),
vacation homes (`vacation_home`), self-rentals (`self_rental`), more than 3
properties (`rental_over_3`). Form 8829: casualty losses
(`home_office_casualty`), homes first used before May 13, 1993 or in recovery
year 40 (`home_depreciation_old`). EIC after a prior disallowance
(`eitc_8862`). Form 8959/8960: RRTA, Form 4137/8919 wages and itemized
investment expenses are not part of v1 facts.

## Output conventions (for PDF field maps)

- Per-column lines carry the column in `line`: Schedule E `"3:A"`, `"21:B"`
  (lines 1b, `2.fair`, `2.personal`, 3-17, 19-22 per property); Form 8829
  two-column lines `"16:a"` (direct) and `"16:b"` (indirect); Schedule EIC
  `"3:1"`, `"4a:1"`, `"4b:1"`, `"5:1"`, `"6:1"` (child 1-3). Every Schedule EIC
  node reads a `dependents[<id>]` fact, so its trace names the child.
- Losses are negative numbers (Schedule E lines 21, 22, 25, 26).
- Not dollars: Form 8829 lines 3 and 41 (`f8829.businessPct.*`,
  `f8829.depreciationPct.*`) are parts per million (125,000 = 12.5%,
  25,640 = 2.564%); lines 1-2 are square feet; Schedule E line 1b is the type
  code and line 2 days; Schedule EIC line 3 is a year, 4a/4b are 1 = yes /
  0 = no, line 5 is 0 (print the relationship from the fact); the student
  loan phase-out ratio is thousandths.
- A value printed on two forms is two nodes: `f8959.total` / `sch2.additionalMedicareTax`,
  `f8959.totalWithheld` / `withholdingOther` (1040 25c), `f8960.tax` / `sch2.niit`,
  `schE.total` / `rentalRoyaltyIncome`, `f8829.allowable.*` / `schC.homeOffice.*`.
