# When a tool says no

Every tool returns `{ ok: false, error: { code, message } }` on failure. Tell the user what happened in plain words (never paste raw JSON), then do what the table says. Don't retry the same call in a loop: at most once after the cause is fixed.

| `code`                   | What it means                                                                                                                                                                                      | What to do                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `STORE_UNREADABLE`       | 1040kit can't decrypt the saved return. Usually the key file (its path is in `message`) was deleted or moved, or the saved file was damaged.                                                       | Stop. Tell the user the key path from the message and ask if they have a backup of that file (for example in Time Machine) to put back exactly there. Never delete, move or overwrite anything in the workspace yourself. If there's no backup, they can start a new workspace in a different folder (`workspace_init({ year, path })`) and re-add their documents; the old folder can be deleted only by them, when they choose. |
| `RETURN_INCOMPLETE`      | `forms_fill` refused: the last `calc_return` wasn't complete, or facts changed since.                                                                                                              | Call `calc_return`. If it's complete, run `return_review` again and go through it with the user, then `forms_fill`. If not complete, handle `missing` (interview) or `unsupported` (`out-of-scope.md`).                                                                                                                                                                                                                           |
| `KB_UNAVAILABLE`         | `kb_search` couldn't reach 1040kit's IRS knowledge base (offline, or the service is down).                                                                                                         | Say so. Answer only from citations you already have from `explain_line` or `deductions_find`; otherwise say you can't confirm it right now. The return itself doesn't need the network.                                                                                                                                                                                                                                           |
| `NOT_IMPLEMENTED`        | This version of 1040kit doesn't have that tool yet.                                                                                                                                                | Tell the user that step isn't available in their version. Suggest updating 1040kit (restart the AI assistant so `npx -y 1040kit` fetches the latest) and trying again. Don't do the step by hand.                                                                                                                                                                                                                                 |
| `IDENTITY_REQUIRED`      | `forms_fill` needs the names and home address that print on the forms; the `message` lists the missing `identity.*` paths.                                                                         | Ask for exactly those (names as on their Social Security cards, street, city, state, ZIP) and record them with `profile_set`. Never ask for SSNs. Then call `forms_fill` again.                                                                                                                                                                                                                                                   |
| `ACK_REQUIRED`           | The user hasn't agreed to the start agreement yet (or its text changed in an update). The `message` holds the exact text.                                                                          | Show the quoted text to the user word for word and ask whether they agree. Only on a clear yes, call `workspace_init` with the same `year` and `path` the message names and `acknowledged: true`, then retry. If they don't agree, stop: 1040kit can't prepare the return without it.                                                                                                                                             |
| `REVIEW_REQUIRED`        | `forms_fill` or `filing_prepare` needs a `return_review` the user confirmed, for exactly the current return: none yet, not confirmed yet, or the facts, documents, names or address changed since. | Call `return_review`, resolve any `blockers`, go through it with the user and ask its `confirmPrompt`. Only when they say it looks good, call `return_review({ workspace, confirmed: true })`, then retry.                                                                                                                                                                                                                        |
| `FORMS_NOT_AVAILABLE`    | `forms_fill` has no official IRS PDFs for this tax year yet (the IRS publishes final forms around January).                                                                                        | Say so. The return is saved; come back after the IRS publishes the forms and 1040kit updates. Don't fill forms by hand from memory.                                                                                                                                                                                                                                                                                               |
| `STATE_REQUIRED`         | `filing_prepare` for mail needs the user's state to pick the IRS mailing address.                                                                                                                  | Ask their state of residence, record `identity.address.state` with `profile_set`, and call `filing_prepare` again.                                                                                                                                                                                                                                                                                                                |
| `PII_IN_OUTPUT`          | 1040kit refused to write a text file because an SSN, EIN or account number would have ended up in it (usually one typed into a name or address field).                                             | Call `profile_get` with the `identity` paths, find the field that holds a number instead of a name or address, and ask the user for the correct value. Never read the number aloud.                                                                                                                                                                                                                                               |
| `UNKNOWN_LINE`           | `explain_line` didn't recognize the line.                                                                                                                                                          | Use an `id` from `calc_return`'s `lines` (or form and line, such as `f1040:16`) and try once more.                                                                                                                                                                                                                                                                                                                                |
| `FILE_OUTSIDE_WORKSPACE` | `expenses_import` only reads files inside the workspace.                                                                                                                                           | Ask the user to save the CSV in the `inbox/` folder and use that path.                                                                                                                                                                                                                                                                                                                                                            |
| `QUERY_EMPTY`            | The `kb_search` query was empty after personal numbers were removed.                                                                                                                               | Rephrase it as a general question without numbers.                                                                                                                                                                                                                                                                                                                                                                                |
| anything else            | An unexpected error.                                                                                                                                                                               | Give the user the message in plain words (without any number that looks like an SSN or account number), suggest restarting the assistant, and if it repeats, reporting it at https://1040kit.com. Don't work around it by hand.                                                                                                                                                                                                   |

## Results that aren't errors

- **`docs_scan` statuses**:
  - `duplicate`: the same file twice; it's ignored. Mention it.
  - `needs_ocr`: a scan or photo 1040kit couldn't read as text yet. Ask for a clearer PDF (the download from the employer's or bank's site is best) or a sharper photo.
  - `encrypted_pdf`: password-protected. Ask the user to save an unprotected copy (open it, print to PDF) into the inbox. Never ask for the password.
  - `unknown`: not a tax form 1040kit recognizes. Ask what it is; if it's not needed, they can move it out of the inbox.
  - `unsupported_form`: a form 1040kit doesn't handle. Its `note` says which and when it's planned. Follow `out-of-scope.md`.
- **`docs_extract` `skipped`**: `corrected_supersedes:<docId>` means a CORRECTED form replaced the original, which is right; mention it. `use_expenses_import` means a bank or card CSV: handle it with `expenses_import` (playbook step 9). `unsupported_image` (for example HEIC photos): ask for a JPG, PNG or PDF. Other reasons (`unreadable`, `unknown_document`, …): explain and ask for a better copy as above.
- **`profile_set` `rejected`**: that answer wasn't saved. Rephrase the question using the `reason` and ask again. Don't invent a different path.
- **`calc_return` with `complete: false`**: not an error. Handle `missing` with the interview and `unsupported` with `out-of-scope.md`.
- **`review_checks` findings**: `error` must be resolved before forms (usually a document typo to confirm with the user, then `profile_set`). `warning` and `info`: explain and let the user decide.
